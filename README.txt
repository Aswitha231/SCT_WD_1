SKILLCRAFT TECHNOLOGY — TASK 01
Responsive Landing Page

FILES
- index.html : page structure and content
- style.css  : design, animations, responsive styling
- script.js  : fixed navbar scroll effect, active section, mobile menu, reveal animation

HOW TO RUN
1. Extract SkillCraft_Task_01.zip.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code extension "Live Server".
4. Test the navbar hover effect, scroll effect, section links, and mobile menu.

NOTES
- The website is self-contained and does not require npm or a build step.
- Google Fonts are loaded from the web; fallback fonts are included.
- Review the content and adjust it to match any specific submission instructions from your faculty.
